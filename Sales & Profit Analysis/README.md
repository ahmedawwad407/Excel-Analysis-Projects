# Sales & Profit Analysis Dashboard — Excel

## 📌 Project Overview

This project analyzes sales and profitability data using Microsoft Excel. The analysis focuses on revenue, profit, sales volume, profitability, and product performance across different years, categories, states, and products.

An interactive Excel dashboard was created using Pivot Tables, Pivot Charts, calculated metrics, and slicers to present key business insights in a clear and user-friendly format.

## 🎯 Business Questions

- Which years generated the highest sales and profit?
- Which product categories are the most profitable?
- Which states have the highest sales volume?
- Which products generate the highest profit?
- Which category has the highest average profit margin?
- How do revenue and cost per unit vary across categories?

## 🔎 Key Insights

1. **Accessories** achieved the highest average profit margin at **56.49%**, indicating strong profitability relative to revenue.

2. **California** recorded the highest total order quantity with **26,761 units**, indicating the strongest sales volume among states.

3. **2016** recorded the highest total order quantity with **37,623 units**, representing the strongest sales volume among the analyzed years.

4. **Bikes** generated the highest average revenue per unit at **1,698**, indicating higher revenue generation per item sold.

5. **Bikes** also had the highest average cost per unit at **1,132**, reflecting the higher cost associated with each unit sold.
